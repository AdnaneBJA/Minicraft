# Minicraft in the browser: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:**
- Ship Minicraft as a WASM page on GitHub Pages.
- Its multiplayer connects over `wss://` to one hosted `minicraft-server`.

**Architecture:**
- **ENet → WebSockets.** The server uses IXWebSocket. The client uses Emscripten's WebSocket API in the browser and
  IXWebSocket in the desktop dev build and the tests.
- **Protocol bytes unchanged.** One message is one binary WebSocket frame.
- **Client loop.** It becomes a per-frame function for `emscripten_set_main_loop`.
- **Web saves.** They live on IDBFS.
- **Server hosting.** The server runs in Docker behind Caddy (TLS) on an Oracle VM.

**Tech Stack:**
- C++20, CMake ≥ 3.25, SDL3 3.4.16, Dear ImGui 1.92.9b, GoogleTest 1.15.2;
- IXWebSocket v12.0.1 (USE_TLS=OFF, USE_ZLIB=OFF);
- Emscripten (emsdk 4.0.x, pinned), Docker, Caddy 2, GitHub Actions (Pages).

**Spec:** `docs/superpowers/specs/2026-10-07-web-build-design.md`

## Global Constraints
- **The protocol format (`net-common/protocol.*`) is unchanged.** One encoded message is one binary WebSocket
  message.
- **The server stays single-threaded** for all lobby/client state. IXWebSocket threads only push events into a
  mutex-guarded queue.
- **The server is never sent to through a dangling socket.** It holds `std::weak_ptr<ix::WebSocket>` and
  `lock()`s before each send.
- **Default port is 7777** (`protocol::kDefaultPort`), and the server listens on `0.0.0.0`.
- **Web server URL:** CMake cache var `MINICRAFT_SERVER_URL`, compiled in as the macro `MINICRAFT_SERVER_URL`.
- **No pthreads in the WASM build**, and no COOP/COEP headers.
- **Saves:** `/persist/saves` on the web; on desktop they stay where they are.
- **Commits:** no Claude/AI co-author or footer lines (user preference); the branch is `web-build`.
- **Code style:** match the existing code: short comments in plain English, `camelCase_` members, and
  `namespace { constexpr ... }` for constants.
- **Deviation from the spec:** IXWebSocket is built with USE_ZLIB=OFF (no zlib on MinGW or in the slim image), so
  no `perMessageDeflate`. Large `Joined` messages travel uncompressed, which WebSockets handle fine.

## Review Focus
1. **A client disconnects while the server is mid-tick sending to it.** No crash; that client's id is cleaned up
   on the next drain. → `server_tests`: `DisconnectDuringTicksIsHarmless`.
2. **The server is unreachable.** The client must report connection lost within about 5 s, not hang in
   "Connecting". → `server_tests`: `UnreachableServerReportsLost`.
3. **A late joiner after many ticks** gets the full history in one large message (over 64 KB). →
   `server_tests`: `LateJoinerGetsHistory` and `LargeJoinedRoundTrips`.
4. **A Hello with an invalid name** returns Error and the client gets no lobby list. → `server_tests`:
   `InvalidNameIsRejected`.
5. **Two clients in one lobby** receive byte-identical tick sequences. → `server_tests`:
   `BothMembersGetSameTicks`.

These go together: ENet can only be removed once the server and the client both move, and the tests need both.

**Files:**

- Modify: `CMakeLists.txt`, `server/server.h`, `server/server.cpp`, `server/main.cpp`, `client/network_client.h`,

**Interfaces:**
- Produces:
  - `struct SocketEvent { enum class Kind { Opened, Message, Closed } kind; std::vector<std::uint8_t> bytes; };`
  - `class ClientSocket { virtual ~ClientSocket(); virtual void open(const std::string& url) = 0; virtual void
    send(std::span<const std::uint8_t>) = 0; virtual std::vector<SocketEvent> poll() = 0; };` (closing =
    destroying)

  - `bool Server::start(std::uint16_t port); void Server::run(); void Server::stop();`
  - `std::string NetworkClient::urlFor(const std::string& address)`: `"host[:port]"` → `"ws://host:port"`, and
    `ws://`/`wss://` URLs pass through.

- [ ] **Step 2: Write the failing tests** in `server/tests/server_test.cpp`. The helper `pump(clients, predicate,
  timeout)` polls the clients every 5 ms until the predicate holds or 5 s pass. A fixture starts the `Server` on
  port `27777 + test index` in a `std::jthread`, and `stop()`s and joins it in TearDown.

  The tests:
  - `ConnectGetsWelcomeAndLobbyList`
  - `CreateAndJoinLobby`: A creates; B sees the lobby in its list and joins; both get `Joined`.
  - `BothMembersGetSameTicks`: after both have joined, collect 30 ticks from each and compare equal from the
    first tick both have.
  - `ChatReachesLobby`
  - `LeaveIsAnnounced`: B disconnects, and A gets the chat line "B left the game".
  - `LateJoinerGetsHistory`: A creates and polls until `ticksWaiting() >= 120` (about 2 s). B joins, and
    `joined->history.size() >= 120`.
  - `LargeJoinedRoundTrips`: a `Joined` holding 6000 synthetic two-player ticks encodes to over 64 KB. A native
    `ClientSocket` sends it to a tiny `ix::WebSocketServer` echo started in the test; the echoed bytes decode to an
    equal `Joined`.
  - `InvalidNameIsRejected`: the name `"bad name!"` → `takeError()` has a value, and `takeLobbies()` stays empty
    for 300 ms.
  - `UnreachableServerReportsLost`: connect to `localhost:1`; `takeConnectionLost()` is true within 6 s.
  - `DisconnectDuringTicksIsHarmless`: A and B are in a lobby; B is destroyed mid-stream, A keeps getting ticks
    for 0.5 s, and the server is still alive (a third client connects and gets Welcome).

  Ticks are compared on `TickInput::tick` plus the turns' `playerId`. Add `operator==` in the test file if
  `TickInput` has none.

- [ ] **Step 3: Run it to see it fail** (it doesn't compile: no `ClientSocket`, `Server::stop`).
  `cmake --build build --target server_tests`.

- [ ] **Step 4: Write `client_socket.h` and `client_socket_native.cpp`.**
  - The native implementation owns an `ix::WebSocket` with `disableAutomaticReconnection()`,
    `setHandshakeTimeout(5)`, `setUrl(url)`, and `start()`.
  - Its callback maps `Open` → Opened; `Message` → Message (bytes copied from `msg->str`); `Close`/`Error` →
    Closed. These go onto a `std::mutex`-guarded `std::vector<SocketEvent>`. `poll()` swaps that vector out.
  - `send` → `sendBinary(std::string(bytes.begin(), bytes.end()))`.
  - The destructor calls `stop()`.
  - A function-local static calls `ix::initNetSystem()` once (needed on Windows).

- [ ] **Step 5: Server.**
  - `server.h`:
    - drop ENet;
    - `Client { std::weak_ptr<ix::WebSocket> socket; int id; std::string name; int lobbyId; }`;
    - `std::map<int, Client> clients_` keyed by id;
    - `std::unique_ptr<ix::WebSocketServer> socketServer_`;
    - the event queue `struct NetEvent { enum Kind { Connected, Message, Disconnected } kind; int clientId;
      std::weak_ptr<ix::WebSocket> socket; std::string bytes; };`, with `std::mutex`,
      `std::condition_variable`, `std::deque<NetEvent>`;
    - `std::atomic<bool> running_`; `std::atomic<int> nextClientId_{1}`.
  - `start(port)`:
    - `ix::initNetSystem()`;
    - `socketServer_ = make_unique<ix::WebSocketServer>(port, "0.0.0.0", backlog 5, protocol::kMaxPlayers)`;
    - in `setOnConnectionCallback`, allocate an id, push `Connected` with the weak_ptr, and set the socket's
      message callback to push `Message`/`Disconnected` (on `Close`) for that id;
    - `auto [ok, error] = socketServer_->listen(); if (!ok) print + return false; socketServer_->start();`.
  - `run()`: while `running_`:
    - tick if it's due;
    - otherwise, under the lock, `cv.wait_until(nextTick)` for events;
    - swap the queue out and handle each event: Connected → insert the Client, send Welcome; Message → find the
      client and `handleMessage`; Disconnected → `disconnect(client)`.
  - `stop()` sets `running_ = false`, notifies, and stops `socketServer_`.
  - `sendTo(const Client&, const Message&)` encodes the message, then calls `if (auto s = client.socket.lock())
    s->sendBinary(std::string(bytes.begin(), bytes.end()))`. It replaces `sendMessage(peer, ...)` everywhere.
  - Remove `enet_host_flush`.
  - In `main.cpp`, drop `EnetLibrary`, and add a `std::signal` handler that calls `g_server->stop()` for
    SIGINT/SIGTERM so Docker stops cleanly.

- [ ] **Step 6: NetworkClient.**
  - Replace `host_`/`server_` with `std::unique_ptr<ClientSocket> socket_` and `std::uint64_t connectStartMs_`.
  - `connect(address, name)`:
    - empty address → false;
    - otherwise `socket_ = makeClientSocket(); socket_->open(urlFor(address));`, state Connecting, remember the
      start time.
  - `poll()`: for each event:
    - Opened → Online, send Hello;
    - Message → `handleMessage`;
    - Closed → `disconnect(); connectionLost_ = true; return`.
    - If still Connecting after 5000 ms, treat it like Closed.
  - `disconnect()` resets `socket_` (its destructor closes).
  - `send` → `socket_->send(protocol::encode(message))` when Online.
  - Time comes from `std::chrono::steady_clock`, not SDL, so the library stays SDL-free.
  - `urlFor`:
    - keep it if it starts with `ws://` or `wss://`;
    - else split the last `:` to get the port (default 7777);
    - return `"ws://" + host + ":" + port`.

- [ ] **Step 7: Client main.** Remove `#include "enet_util.h"`, the `enet_.ok()` log line, and the `EnetLibrary enet_`
  member. Delete `net-common/enet_util.h`. Change "over ENet" to "over WebSockets" in the protocol comments.

- [ ] **Step 8: Build everything and run the tests.** Use the PATH from the local-toolchain memory, then

- [ ] **Step 9: Manual check.** Run `minicraft-server` and two `Minicraft` windows on `localhost`; create and join a
  lobby, walk around, and chat.

- [ ] **Step 1: `client_socket_web.cpp`.**
